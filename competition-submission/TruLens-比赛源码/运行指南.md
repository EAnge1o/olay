# TruLens 运行指南

## 1. 环境要求

- Python 3.11 或更高版本
- Node.js 22 LTS 或更高版本
- npm 10 或更高版本
- 可选：本机 Google Chrome（小红书链接抓取）
- 可选：Docker Desktop（容器化启动后端）

项目默认可以使用 SQLite 和规则回退模式启动。完整多模态分析需要用户自行提供模型服务 API Key。

## 2. 目录说明

```text
TruLens-比赛源码/
├── frontend/                  前端源码
├── backend/                   FastAPI 后端
├── content-trust-engine-v10/  内容可信度分析引擎
├── xhs/XhsExtractor/          小红书抓取器
├── README.md
└── 运行指南.md
```

## 3. 最小本地启动

### 3.1 启动后端

在项目根目录执行：

```bash
cd backend
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python run.py
```

macOS / Linux：

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
python run.py
```

后端默认地址：`http://127.0.0.1:8000`  
接口文档：`http://127.0.0.1:8000/docs`  
健康检查：`http://127.0.0.1:8000/api/health`

`.env.example` 的默认配置不会调用外部模型，也不会启用小红书抓取，适合先验证项目能否启动。

### 3.2 启动前端

另开一个终端：

```bash
cd frontend
npm ci
npm run dev
```

浏览器访问：`http://localhost:8443`

前端开发服务器会把 `/api` 代理到 `http://127.0.0.1:8000`。如果后端地址不同，可设置：

```powershell
$env:VITE_API_TARGET="http://127.0.0.1:8000"
npm run dev
```

## 4. 启用完整分析引擎

推荐使用 Python 3.11 或 3.12。

在 `backend/` 目录中继续安装引擎依赖：

```bash
python -m pip install -r requirements-engine.txt
python -m pip install -e ../content-trust-engine-v10
```

编辑 `backend/.env`：

```dotenv
TRUST_ENGINE_ENABLED=true
DEEPSEEK_API_KEY=your_deepseek_key
DEEPSEEK_MODEL=deepseek-flash
GLM_API_KEY=your_glm_key
GLM_MODEL=glm-5.3-flashx
```

说明：

- 未填写 `DEEPSEEK_API_KEY` 时，文本、评论和账号维度会使用引擎内置规则回退。
- 未填写视觉模型 Key 时，图片维度会明确标记为不可用，不会伪造分数。
- 不要把真实 `.env` 或 API Key 一起提交。

## 5. 启用小红书链接功能

小红书公开笔记链接默认不要求登录，但需要本机 Chrome。打开一个小红书帖子复制链接输入即可进行分析。

在 `backend/` 目录中执行：

```bash
python -m pip install -r requirements-xhs.txt
```

编辑 `backend/.env`：

```dotenv
XHS_ENABLED=true
XHS_USER_DATA_PATH=./storage/chrome-profile
XHS_HEADLESS=false
```

如果目标链接返回登录页或“安全限制”页面，再执行一次登录并复用会话：

```bash
python scripts/xhs_login.py
```

抓取测试：

```bash
python scripts/xhs_smoke_test.py "https://www.xiaohongshu.com/explore/..." --analyze
```

可选的登录态保存在 `backend/storage/chrome-profile`。该目录已被
`.gitignore` 排除，不应打包或公开。

## 6. 运行测试

### 后端

```bash
cd backend
python -m pip install -r requirements-dev.txt
python -m pytest
```

### 分析引擎

```bash
cd content-trust-engine-v10
python -m pip install -e ".[dev]"
python -m pytest
```

### 前端生产构建

```bash
cd frontend
npm ci
npm run build
```

构建结果输出到 `frontend/dist/`，该目录不包含在提交源码中。

## 7. Docker 启动后端（可选）

在项目根目录执行：

```bash
docker compose -f backend/docker-compose.yml up --build
```

默认镜像会安装 `content-trust-engine-v10`。如需只启动后端启发式版本：

```bash
docker build --target lean -f backend/Dockerfile -t trulens-api-lean .
docker run --rm -p 8000:8000 trulens-api-lean
```

前端仍按第 3.2 节单独启动。

## 8. 数据库与持久化

- 默认数据库：`backend/storage/trulens.db`
- 默认上传目录：`backend/storage/uploads`
- 生产环境可使用 PostgreSQL，配置示例见 `backend/.env.example`
- 首次启动会自动创建所需目录和数据表

`backend/storage/` 是运行时数据目录，不属于源码提交内容。

## 9. 常见问题

### 前端能打开但分析请求失败

确认后端运行在 `8000` 端口，并检查 `VITE_API_TARGET`。

### 图片维度显示不可用

确认已设置 `GLM_API_KEY`，或使用 `QWEN_API_KEY` 作为备用配置。

### 小红书链接抓取失败

确认：

1. `XHS_ENABLED=true`
2. 已安装 Chrome 和 `requirements-xhs.txt`
3. 如遇到登录页，已运行 `python scripts/xhs_login.py` 并完成登录
4. `XHS_USER_DATA_PATH` 指向可写的浏览器 profile 目录

### 保存数据后想重置演示

停止后端，删除 `backend/storage/trulens.db` 和 `backend/storage/uploads/`，再次启动即可重新初始化。
