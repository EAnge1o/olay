TruLens 测试数据包 · 高仿伪造内容样本集
================================================
团队：No Five Days　　赛题：赛题 2「信任守护师 — 创造者的 AI 卫士」
用途：用于测试内容核验 Agent 能否识别种草内容、商品评论、评论区、客服投诉与 AI 生成素材中的合成 / 篡改 / 伪造痕迹，并给出可解释的判定依据。

一、数据规模
  样本总数：22 条（sample_011 – sample_032）
  伪造样本：18 条　　对照样本（无伪造，用于检验误报）：4 条
  标注疑点：共 94 处，每处可定位到具体文件与位置
  伪造样本场景分布：综合（5 类场景） 1 条、种草内容 3 条、AI 生成素材 5 条、商品评论 3 条、评论区 3 条、客服投诉 3 条
  伪造样本难度分布：易–中 1 条、易 5 条、中 7 条、难 5 条
  （主数据包 sample_001 – sample_010 另行提交，编号与本包连续、互不重复）

四、建议评估方法
  1. 让模型对每个样本输出 [{id, hit, reason}] 与总体结论（是否伪造 / 风险等级）；
  2. 与 labels.json 逐条比对，计算疑点召回率（命中数 / 标注数）；
  3. 模型报出、但标注中不存在的疑点计为误报；对照样本（sample_029–032）上报出的任何「伪造」结论均计为误报；
  4. 每个样本 meta.txt 的「期望模型输出」给出了必查疑点与合格线；
  5. 难度说明：易 = 单一明显痕迹；中 = 需要比对或结合常识；难 = 单看正文几乎无信号，需要跨文件 / 账号层 / 像素级交叉验证。

五、数据来源与合规说明
  · 全部样本为团队自行制作的合成测试数据，「来源平台」为模拟（小红书 / 电商平台样式），不对应任何真实笔记或订单；
  · 品牌范围仅限欧莱雅（L'Oréal Paris）及其同系列产品，未涉及其他品牌；
  · 账号昵称、店铺、订单号、运单号、客服工号、报告编号、检测机构、专家姓名均为虚构；售后与负面情节只指向虚构第三方店铺，不指向品牌官方渠道；
  · 图片中的伪造（局部磨皮、整图调色、拼接贴标、文字篡改、着色、镜像复用、伪造截图 / 报告 / 图表）均为团队后期制作，具体方式写在各样本 meta.txt 的 fake_method；
  · sample_011 的原有说明保留在其 README.txt 中。
